=====================================================================
  AION 2 WINGMAN 1.0                                        by VaLeTecK
  AION 2용 QoL 도구: 빠른 텔레포트 도우미 + HUD 오버레이
=====================================================================

소개
  AION 2와 함께 실행되는 AutoHotkey v2 프로그램으로 다음 기능을 제공합니다.
  - HUD 오버레이: 매크로 신호(F9 / F10)에 맞춰 켜지는 조준선, 바,
    LOOT / COMBAT 아이콘.
  - Hidden Cube: Hidden Cube 창이 열리면 마우스를 "Open with Key"
    버튼으로 옮기고 그 자리에 고정합니다.
  - 빠른 텔레포트 도우미 (Field Boss): 지도를 열면 모든 보스가 있는
    패널을 표시합니다 (A-Z, 등급, 출현 / 미출현).
    ULTRA-FAST MODE (기본값): 보스를 클릭하면 Wingman이 Kibelisk 목록에서
    Teleport를 스스로 찾아 줍니다. 클릭하고 F를 두 번 누르면 끝.
    이후 화살표가 비행 방향을 알려 줍니다.
    NORMAL MODE: 가장 가까운 Teleport까지 전체 안내 경로.
  - 설정 창, 해상도 프리셋, 성능 프로필,
    12개 인터페이스 언어와 22가지 테마 (클래스 8개, 이벤트 7개)
    와 직접 저장한 테마.

  이 스크립트는 게임에서 대신 클릭하거나 키를 누르지 않습니다.
  커서만 옮기고 할 일을 보여 줄 뿐, 클릭은 직접 합니다.

패키지 구성
  FIRST RUN QUICK-SETUP.bat  최초 실행 설정 (필수 구성 요소)
  AION 2 Wingman.ahk         프로그램 본체
  OCR.ahk                    OCR 라이브러리 (Field Boss에 사용)
  README\                    여러 언어로 된 이 안내서

요구 사항
  - Windows 10 또는 11
  - AutoHotkey v2 (설정 프로그램이 설치)
  - Windows 영어 OCR (설정 프로그램이 설치)
  - 영어 AION 2 클라이언트 (Field Boss는 영어 이름을 읽습니다)

설치
  1. 압축을 풀기 전에: zip 우클릭 > 속성 > "차단 해제" 체크 > 확인.
     (Windows 경고를 줄여 줍니다.)
  2. zip을 고정된 폴더에 압축 해제하세요. 예: 문서\AION 2 Wingman.
     zip 안에서 바로 실행하지 마세요.
  3. "FIRST RUN QUICK-SETUP.bat"를 더블클릭하고 관리자 권한 요청을
     허용합니다. 모든 항목을 확인·설치한 뒤, 바탕 화면 바로 가기를
     만들고 바로 실행할 수 있습니다.
     "Windows의 PC 보호" 창이 뜨면: "추가 정보" > "실행".
     설정 중에 안내 마법사가 언어, 해상도, 성능, 기능 켜기/끄기를
     설정합니다.
  4. 다음부터는 "AION 2 Wingman.ahk"(또는 바로 가기)를 실행하세요.
     게임이 앞에 있을 때 키를 읽기 위해 스스로 관리자 권한을 요청합니다.

첫 실행 시 먼저 할 일
  - 설정 열기: Ctrl+Shift+F12 (또는 작업 표시줄의 초록색 "H" 아이콘
    더블클릭).
  - 언어는 설정 프로그램에서 이미 고릅니다 (⚙️ 일반 > 언어에서 변경).
  - 📦 Preset: 화면에 맞게 FullHD (1080p), 2K (1440p), 4K (2160p) 중
    하나를 적용하면 HUD 크기가 맞춰집니다.
  - "저장 후 재시작"로 확정. "실시간 미리보기"를 켜면 게임 없이도
    변경 사항을 바로 볼 수 있습니다.

기본 키 (설정 > ⌨️ 키에서 변경)
  Ctrl+Shift+\      HUD 오버레이 켜기/끄기
  Ctrl+Shift+1      Hidden Cube 켜기/끄기
  Ctrl+Shift+2      Field Boss 켜기/끄기
  Ctrl+Shift+F12    설정 (게임 밖에서도 동작)
  Esc               진행 중인 Field Boss 안내 취소
  M / F             게임의 지도 / Travel 키 (스크립트가 감지)
  F9 / F10          HUD용 매크로 신호 (아래 참고)
  Ctrl+F11, Ctrl+Shift+F6/F7/F8   진단 (문제가 있을 때만)
  (\ = 이탈리아어 키보드에서 1 왼쪽 키. 다른 자판에서는 설정에서
   원하는 키로 바꾸세요.)

매크로를 HUD에 연결하기
  - 전투 매크로: 매크로 내내 F9를 반복 입력.
  - 루팅 매크로: F10을 넣고 1350 ms 대기.
  키 입력은 게임에도 그대로 전달됩니다.

Field Boss 사용법
  1. 지도(M)를 엽니다. 위쪽에 키 안내, 오른쪽에 보스 패널이 나타납니다
     (등급/상태 필터, ▲/▼로 접기).
  2. 패널에서 보스를 클릭하면 단계별 안내가 시작됩니다. 마우스가 알맞은
     위치로 이동(고정)되고 아래에 큰 "단계 n" 안내가 표시됩니다.
     클릭은 직접 합니다.
  3. Teleport를 클릭한 뒤 F를 두 번 누르면(Travel) 마우스 고정이 풀리고
     위쪽에 보스 방향 화살표가 표시됩니다.
  Esc로 언제든 취소할 수 있습니다.

자주 묻는 문제
  - 게임에서 아무 일도 없음: AION2.exe 창이 앞에 있을 때만 동작합니다.
    작업 표시줄의 "H" 아이콘을 확인하세요.
  - Field Boss "사용 불가": 폴더에 OCR.ahk가 없거나 Windows 영어 OCR이
    없습니다. 설정 프로그램을 다시 실행하세요.
  - HUD가 너무 크거나 작거나 위치가 어긋남: 알맞은 프리셋을 적용하세요.
  - 백신이 스크립트를 차단: AutoHotkey에서 흔한 오탐입니다. 폴더를
    예외에 추가하세요.
  - 설정 변경 후 문제가 생기면: 스크립트 옆에 백업
    "AION 2 Wingman.ahk.bak"가 있습니다.

업데이트와 개인 설정
  업데이트는 새 스크립트로 덮어쓰기만 하면 됩니다. 설정(보스 목록과
  프리셋 포함)은 %AppData%\AION 2 Wingman에 저장되어 첫 실행 때 자동으로
  복원됩니다. 처음부터 다시 하려면 그 폴더를 삭제하세요.

유지 관리와 종료
  설정 > 🛠️ 유지 관리: 설치 마법사를 다시 실행하고 Wingman 폴더와
  개인 설정 폴더를 엽니다.
  위쪽의 빨간 "⏻ Wingman 종료" 버튼은 설정 창이 아니라 프로그램 전체를
  종료합니다.
  메뉴 위의 🔍 칸으로 모든 설정을 검색할 수 있습니다.

제거
  프로그램 종료("⏻ Wingman 종료" 또는 "H" 아이콘 > Exit) 후 폴더와 바로 가기를 삭제하세요.
  AutoHotkey는 Windows 설정 > 앱에서 제거합니다.
