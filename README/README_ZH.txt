=====================================================================
  AION 2 WINGMAN 1.0                                        by VaLeTecK
  AION 2 的 QoL 工具：快速传送助手 + HUD 叠加层
=====================================================================

简介
  一个与 AION 2 同时运行的 AutoHotkey v2 程序，提供：
  - HUD 叠加层：准星、条形和 LOOT / COMBAT 图标，随你的宏
    发出的信号（F9 / F10）点亮。
  - Hidden Cube：Hidden Cube 窗口打开时，把鼠标移到 "Open with Key"
    并固定在那里。
  - 快速传送助手（Field Boss）：打开地图时显示包含所有首领的面板
    （A-Z、等级、已出现 / 未出现）。
    ULTRA-FAST MODE（默认）：点击首领，Wingman 自动在 Kibelisk 列表中
    找到它的 Teleport，点击后按两次 F 即可。随后箭头会显示飞行方向。
    NORMAL MODE：完整引导到最近的 Teleport。
  - 完整的设置窗口、分辨率预设、性能配置、
    12 种界面语言和 22 种主题（8 种职业、7 种节日）
    以及自己保存的主题。

  脚本不会替你在游戏里点击或按键：它只移动光标并提示你该做什么，
  点击由你自己完成。

压缩包内容
  FIRST RUN QUICK-SETUP.bat  首次运行安装（依赖项）
  AION 2 Wingman.ahk         主程序
  OCR.ahk                    OCR 库（Field Boss 使用）
  README\                    多语言说明

系统要求
  - Windows 10 或 11
  - AutoHotkey v2（由安装程序安装）
  - Windows 英语 OCR（由安装程序安装）
  - 英文版 AION 2 客户端（Field Boss 读取英文名称）

安装
  1. 解压前：右键 zip > 属性 > 勾选"解除锁定" > 确定。（避免 Windows 警告）
  2. 把 zip 解压到固定文件夹，例如 文档\AION 2 Wingman。
     不要直接在 zip 里运行文件。
  3. 双击 "FIRST RUN QUICK-SETUP.bat" 并允许管理员权限。安装程序会检查并
     安装所需内容，最后可创建桌面快捷方式并启动程序。
     如出现"Windows 已保护你的电脑"：点"更多信息" > "仍要运行"。
     安装过程中，向导会设置语言、分辨率、性能和功能开关。
  4. 以后直接运行 "AION 2 Wingman.ahk"（或快捷方式）。它会自动请求
     管理员权限：游戏在前台时读取按键需要该权限。

首次运行：先做这些
  - 打开设置：Ctrl+Shift+F12（或双击任务栏中的绿色 "H" 图标）。
  - 语言已在安装程序中选择（可在 ⚙️ 常规 > 语言 中更改）。
  - 📦 Preset：根据屏幕应用 FullHD (1080p)、2K (1440p) 或 4K (2160p)，
    让 HUD 尺寸正确。
  - 点 "保存并重启" 确认。开启 "实时预览" 可在不开游戏时
    实时查看效果。

默认按键（在 设置 > ⌨️ 按键 中修改）
  Ctrl+Shift+\      HUD 叠加层 开/关
  Ctrl+Shift+1      Hidden Cube 开/关
  Ctrl+Shift+2      Field Boss 开/关
  Ctrl+Shift+F12    设置（游戏外也可用）
  Esc               取消正在进行的 Field Boss 引导
  M / F             游戏的地图键和 Travel 键（脚本会"监听"）
  F9 / F10          给 HUD 的宏信号（见下文）
  Ctrl+F11、Ctrl+Shift+F6/F7/F8   诊断（仅在出问题时使用）
  （\ = 意大利键盘上 1 左边的键；其他键盘布局请在设置中改成自己的按键。）

如何把宏连接到 HUD
  - 战斗宏：在整个宏期间连续按 F9。
  - 拾取宏：加入 F10，并等待 1350 毫秒。
  按键仍会正常发送到游戏。

如何使用 Field Boss
  1. 打开地图（M）。顶部出现按键说明，右侧出现首领面板
    （品级/状态筛选，▲/▼ 折叠）。
  2. 在面板中点击一个首领，分步引导开始：鼠标被移动（并锁定）到正确
     位置，底部显示大号 "步骤 n" 提示。由你点击。
  3. 点击 Teleport 后按两次 F（Travel）。鼠标解锁，顶部出现指向首领
     方向的箭头。
  随时按 Esc 取消。

常见问题
  - 游戏里没反应：只有 AION2.exe 在前台时脚本才工作。检查任务栏的
    "H" 图标。
  - Field Boss "不可用"：文件夹里缺少 OCR.ahk 或缺少 Windows 英语 OCR。
    重新运行安装程序。
  - HUD 太大/太小或位置不对：应用合适的预设。
  - 杀毒软件拦截脚本：AutoHotkey 常见误报，把文件夹加入排除项。
  - 修改后出问题：脚本旁边有备份 "AION 2 Wingman.ahk.bak"。

更新与个人设置
  更新时只需用新脚本覆盖旧脚本：你的设置（包括首领列表和预设）保存在
  %AppData%\AION 2 Wingman 中，首次启动时会自动恢复。
  如需从头开始，删除该文件夹即可。

维护与退出
  设置 > 🛠️ 维护：重新运行安装向导，打开 Wingman 文件夹和个人设置文件夹。
  顶部红色的 "⏻ 退出 Wingman" 按钮会关闭整个程序，而不只是设置窗口。
  菜单上方的 🔍 框可搜索所有设置。

卸载
  关闭程序（"⏻ 退出 Wingman" 或 "H" 图标 > Exit），删除文件夹和快捷方式。
  AutoHotkey 可在 Windows 设置 > 应用 中卸载。
